# Emoji Animation

Emoji Animation built using HTML, CSS and JavaScript.

## Preview

![Animation Preview](./Screenshot%202024-08-25%20195016.png)

## About

A small, self-contained demo that demonstrates simple emoji-based animations using CSS and a bit of JavaScript. The project is intentionally minimal — open the `index.html` file in your browser to run the demo.

## Features

- Pure frontend (no build step required)
- Lightweight HTML/CSS/JS
- Easily customizable styles in `style.css`

## Getting started

1. Clone the repository:

```bash
git clone https://github.com/BinaryVortex/Emoji-Animation.git
cd Emoji-Animation
```

2. Open `index.html` in your browser (double-click or serve with a static server).

## Customization

- Edit `style.css` to change animation speed, colors, layout, or emoji appearance.
- Edit `index.html` to add/remove emoji elements or change the structure.

## File structure

- `index.html` — demo page
